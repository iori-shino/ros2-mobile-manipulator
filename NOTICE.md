# Ownership and licence status

The project author confirms that the ten robot STL assets were self-modelled and do not contain downloaded third-party CAD. Sensor housings and room objects are project-created primitive geometry. See `docs/ASSET_PROVENANCE.md` for the file inventory and hashes.

No open-source licence has yet been selected for this project or its CAD assets. Existing ROS package licence metadata remains `Proprietary`; no MIT, Apache, Creative Commons or other reuse grant is implied by this release preparation. The author must decide the licensing terms before advertising the project as open source.

ROS 2, Gazebo, ros2_control, SLAM Toolbox and other system dependencies are installed separately and retain their own licences. No commercial CAD software, downloaded standard-part mesh or dependency source code is bundled.

Development assistance from OpenAI Codex is disclosed in README. This notice does not attribute authorship of upstream dependencies to the project author.
